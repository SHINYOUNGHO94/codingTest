# 오답 기록

실패한 입력만 적지 않고 원인과 예방 방법도 함께 기록한다. Claude Code는
이 문서를 바탕으로 약점을 보완하는 변형 문제를 만든다. Codex는 다음 학습
주제를 제안할 때 이 문서를 참고한다.

| 날짜 | 언어 | 직무 | 문제 | 분류 | 증상 또는 실패 입력 | 원인 | 예방 방법 | 변형 문제 필요 여부 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

## 분류

- 요구사항 이해 오류
- 엣지 케이스 누락
- 타입 또는 런타임 안전성
- 입력값 변경
- 시간 복잡도
- 공간 복잡도
- 비동기 오류 처리
- REST API 설계
- SQL 정확성
- 테스트 범위
- 가독성
